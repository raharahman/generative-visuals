# Generative Visuals · p5.js 🎨🍵

My work for the **Creative Making: Generative Visuals** unit (BSc Creative Computing, UAL). Week by week, it builds up a visual world for my matcha brand, **Nat'Cho Matcha**, in the **Kagoshima Series**: Sakurajima volcano, tea fields and matcha bowls.

Click **▶ Run it** to see any piece live in your browser.

## What I practised
Shapes and colour · loops and nested loops · arrays and palettes · `map()`, `dist()`, `sin()` and `cos()` · mouse interaction · animation with `frameCount` · writing my own functions · transformations (`push`/`translate`/`rotate`) · pixel manipulation

## Run locally
Open any folder's `index.html` in a browser (it loads p5.js from a CDN), or click the live links above.

*AI use: my course allows declared AI support. Where AI helped (for example, with coordinates or colour values), the code comments say so.*
